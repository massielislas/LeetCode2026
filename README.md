# LeetCode2026

This repository holds my LeetCode solutions for AI prep in 2026.

## Structure

- `src/main/java/org/solutions/` — one class per solved problem
- `src/test/java/org/solutions/` — JUnit 5 tests for each solution
- `claudeInstructions.md` — conventions for adding new solutions/tests

## Solutions

| Solution | Description |
|----------|-------------|
| TwoSum | Find indices of two numbers that add up to a target |
| ReverseWords | Reverse the order of words in a string |
| MergeStringsAlternately | Merge two strings by alternating characters |

## Build & Test

This is a Gradle/Java project using JUnit 5.

```
./gradlew test
```
